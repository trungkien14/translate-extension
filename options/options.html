Translation provider

Free anonymous quota is about 5,000 characters per day. Adding an email raises it to about 50,000 per day (MyMemory's published limits). The email is sent to MyMemory with each request.

LibreTranslate is free only when self-hosted. The public libretranslate.com needs a paid API key. Saving asks your browser for permission to contact the server.

Needs a Google Cloud project with billing enabled and the Cloud Translation API on. The key is stored only in this browser profile and is never read by web pages.

Create a Translator resource in the Azure portal (Microsoft's pricing page lists a free tier of 2 million characters per month; an Azure account is required). Copy its key here. If your resource is regional (not “Global”), also enter its region, e.g. southeastasia.

Pronunciation

The speaker buttons use your browser's text-to-speech voices. This is synthesized speech, not a recording of a native speaker. Dictionary recordings, when available, are labeled as such.

No voices were reported by this browser. Install system voices in your OS language settings.

Keyboard shortcut

Default: Alt + Shift + T translates the current selection. Brave does not let extensions open its shortcut page from a link, so paste this address into the address bar to change it:

brave://extensions/shortcuts
