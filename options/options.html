Translation provider

Free anonymous quota is about 5,000 characters per day. Adding an email raises it to about 50,000 per day (MyMemory's published limits). The email is sent to MyMemory with each request.

Create a key in Google AI Studio (aistudio.google.com → Get API key) with a normal Google account. Google lists a free tier without billing. Privacy: on the free tier, Google may use the text you send to improve its products. Do not translate confidential text with it.

Model names change over time. If you see “model not found”, copy a current Flash model name from AI Studio.

Security of API keys

Convenient, but the unlock key is then stored on disk, so encryption only stops casual reading, not someone who copies your browser profile. “Lock now” forgets it.

Saved keys are never shown again on this page; type a new one to replace it. The passphrase is not stored anywhere. If you forget it, the keys cannot be recovered: use “Remove all saved keys” and enter them again. Encryption protects keys stored on disk; it cannot protect against malware that is already running on your computer or watching your keyboard. Also keep the keys safe at their source: use a dedicated key, set a quota or budget alert, and revoke it in the provider's console if you suspect a leak.

Pronunciation

The speaker buttons use your browser's text-to-speech voices. This is synthesized speech, not a recording of a native speaker. Dictionary recordings, when available, are labeled as such.

No voices were reported by this browser. Install system voices in your OS language settings.
